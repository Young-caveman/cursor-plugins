## Vendor guidance (for rewriting skill text)

- OpenAI, "Rethinking skills and prompts for GPT-6 Astra" (2026-09-11): short skill descriptions; "overly specific guidance can now hinder results"; mandatory test or stop-for-review steps cause over-testing or early stops. GPT-5.6 guide: leaner prompts ~10–15% better with 41–66% fewer tokens.
- OpenAI latest-model guide: GPT-6 follows skill files and AGENTS.md more literally; recommends stating that user instructions override skills.
- Anthropic, claude.dev/blog (2026-09-22, 09-25): Opus 5.5 defaults `medium`; raise to `high` when it stalls; `xhigh`/`max` only with a measured gain; don't carry effort levels across models; a retry costs more than token savings; drop "think carefully" lines.
