# PStack development plan

Created at: 2026-09-22 20:28:56 UTC (2026-09-23 05:28:56 Asia/Tokyo)

## Goal

Gradually adapt PStack into a practical personal engineering baseline. Initial targets are Codex and OpenCode running inside T3 Code, primarily on macOS and Omarchy/Arch Linux. T3 Code is the outer session and worktree environment; Codex and OpenCode are the harnesses.

## Planned work

1. Keep shared model-routing semantics clear: skills may request an allowed model profile and reasoning level; the active harness resolves them to its concrete configuration.
2. Account for Codex and OpenCode configuration and inheritance differences. Do not assume their automatic or parent-inheritance behavior is interchangeable.
3. Keep model choices explicit and bounded. Do not silently substitute a model or raise reasoning effort when a requested profile cannot be resolved.
4. Document setup and installation by harness, including project-scoped installs for isolated manual tests.
5. Have the user perform real Codex and OpenCode installation and harness checks. Prefer a free or low-cost OpenCode model when available.
6. Use those results to choose the next narrow setup/model-routing changes before expanding to other PStack areas.
